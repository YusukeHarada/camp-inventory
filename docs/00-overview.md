## このアプリは何をしているか

「キャンプ用品管理アプリ」は、ブラウザで動く Webアプリです。  
スマートフォン（iPhone）や PC のブラウザから使えます。

**できること：**
- キャンプ用品（ギア）を登録・編集・削除
- キャンプの予定を立て、持ち物チェックリストを作る
- 「このテントは3回持っていった」という使用履歴を見る
- Google アカウントでログインして、データはクラウドに保存

## 技術スタックの役割（C言語との対比）

| この技術 | 役割 | C言語で言うと |
|---------|------|------------|
| **TypeScript** | プログラミング言語 | C言語（型チェックが厳密） |
| **React** | 画面（UI）を作るライブラリ | ncurses（ターミナルUI）に近い |
| **Next.js** | Webアプリのフレームワーク | Makefile + main.c のような骨格 |
| **Firebase Auth** | ユーザー認証 | PAM / /etc/passwd の認証に相当 |
| **Firestore** | データベース（NoSQL） | SQLite に相当（ただしクラウド） |
| **Tailwind CSS** | スタイル（見た目） | 色や余白の定義 |
| **Vercel** | ホスティング（公開・実行） | サーバーに `./a.out` を置いて実行 |

## アーキテクチャ（層の構造）

このアプリは「層（レイヤー）」に分かれています。  
C言語で「ハードウェア層・OS層・アプリ層」と分けるのと同じ発想です。

```
┌─────────────────────────────────────────┐
│  画面（UI）層                            │
│  src/app/**, src/components/**          │
│  ユーザーが目に見える部分。ボタン・一覧表示 │
└──────────────────┬──────────────────────┘
                   │ 「追加ボタンを押した」
                   ▼
┌─────────────────────────────────────────┐
│  状態管理層（フック）                     │
│  src/hooks/useGears.ts など             │
│  データの読み書き・更新をまとめて管理      │
└──────────────────┬──────────────────────┘
                   │ DB に書き込む
                   ▼
┌─────────────────────────────────────────┐
│  データベース操作層                       │
│  src/lib/firestore/gears.ts など        │
│  Firebase Firestore への CRUD 操作       │
└──────────────────┬──────────────────────┘
                   │ HTTP 通信
                   ▼
┌─────────────────────────────────────────┐
│  クラウド（Firebase）                    │
│  Googleのサーバー上にデータを保存         │
└─────────────────────────────────────────┘
```

## ユーザー操作の流れ（例：ギアを追加）

```
[ユーザー]「追加」ボタンをクリック
     ↓
[gears/page.tsx]  showAddModal = true（モーダルを開く）
     ↓
[GearForm.tsx]    フォームを表示・入力
     ↓
[Zod バリデーション]  入力値をチェック（エラーがあれば表示）
     ↓
[gears/page.tsx]  handleAdd() 関数が呼ばれる
     ↓
[useGears.ts]     addGear() フックが呼ばれる
     ↓
[lib/firestore/gears.ts]  Firestore に addDoc() で書き込み
     ↓
[Firestore]       Googleサーバーにデータ保存
     ↓
[useGears.ts]     load() でデータ再取得
     ↓
[gears/page.tsx]  画面が自動で更新される
```

## C言語のプログラムとの最大の違い

### C言語
- `main()` から始まり、処理を順番に実行する
- 画面更新は自分で `printf()` や `refresh()` を呼ぶ
- データ保存は `fwrite()` や `sqlite3_exec()` を自分で管理

### このWebアプリ
- 「イベント」（クリック、データ変更）に反応して動く
- **React が自動で画面を再描画する**（`setState()` を呼ぶだけでよい）
- データ変更は Firebase SDK が管理（ネットワーク通信を隠蔽）
